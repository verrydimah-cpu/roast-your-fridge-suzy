A single-line roast of my fridge, written to `/output/entry.txt`: "My fridge beeps if I leave it open 10 seconds, then quietly lets spinach liquefy in the crisper for three weeks — loud about manners, silent about murder." The joke mocks two specific, recognisable fridge behaviours — the door-open alarm that fires after seconds and the crisper drawer where vegetables quietly rot for weeks — and turns on the final contrast: an appliance loud about manners and silent about murder. The program in `main.ts` (Node 22, standard library only) writes that one line, byte-identically on every run, to `entry.txt` in the output directory (`/output`, or `$MAKEFUN_OUTPUT_DIR` anywhere else), clearing only the directory's contents first.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
